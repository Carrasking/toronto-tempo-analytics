# Toronto Tempo Analytics Dashboard

This project analyzes the Toronto Tempo's 2026 inaugural WNBA season using Python and Matplotlib.

The dashboard highlights key performance and business metrics, including team record, top scorers, Marina Mabrey's scoring trajectory, record-breaking moments, and business insights related to market demand, brand equity, and expansion value.

## Tools Used
- Python
- Matplotlib
- NumPy

## Output
The script generates a visual analytics dashboard as a PNG image ready to be shared on LinkedIn.
